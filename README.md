# タイプ診断

> 個人の試作・初版です。動作は参考情報で、保証はしません。

24の質問に1〜5で答えると、4つの軸の寄りから16タイプの読み物を出します。愛称・強み・つまずきやすい場面・人との関わり方・伸ばすヒントが付きます。個人の試作の初版で、参考情報です。

## 先に知っておいてほしいこと

- **これは診断ではなく、自分を言葉にするための読み物です。** 医療・心理の診断ではありません。質問の妥当性や信頼性を、統計的に検証していません
- **公式のMBTI®(Myers-Briggs Type Indicator)とは別物です。** 質問24問と16タイプの説明は、すべて自作の文です。「INFP」のような4文字の記号は、外向/内向・現実/直感・思考/感情・計画/柔軟の4軸の組み合わせを示すために使っています。MBTIは The Myers & Briggs Foundation の商標です
- **他人の判定や、採用・職場・恋愛の判断材料には使わないでください。** 自分自身の振り返りのためのものです
- 結果は、答えた時点の傾向です。日や状況で変わります。強さの%は、優劣や能力の高さではありません
- **採点と説明文の選択は付属のスクリプト(Python 3)がします。** AIが点数を計算し直すことはありません。AIは「この人にとっての読み解き」の文章だけを書きます
- 追加のライブラリは要りません(Pythonに最初から付いているものだけで動きます)
- **落ち込んでいる時や、強い悩みを抱えている時は、診断より先に話を聞く**作りです。つらさが続く、眠れない、消えたいなどの深刻な内容が出たら、診断を中断して、身近な人や専門の窓口(かかりつけ医、地域の相談窓口)を勧めます。必要な時は、このスキルではなく専門の窓口を頼ってください
- `SKILL.md` に対応しているAIツールで使える作りにしていますが、**動作確認は Claude Code(Windows)だけです。** ほかのAIツール・Mac・Linux は動く想定で、確認していません

## できること

- **診断**: 24問に答えて、4軸の寄りと16タイプを出す。点数が拮抗している軸は「境界」と表示し、断定しない
- **読み物**: タイプごとの愛称・強み・つまずきやすい場面・人との関わり方・伸ばすヒント
- **前回との変化**: 結果を保存してあれば、前回との違いを伝える
- 表示は文字の枠、または自分のPCで開くHTMLページです

## ほかのスキルとの連携(入っている時だけ)

同じ作者の別スキルが同じ場所に入っていると、連携して使います。入っていなくても単独で動きます。

- `占い`: 同じ人の占いの結果と並べて読み、重なる所と違う所を伝える
- `名言`: タイプごとに、つまずきやすい所に合う名言のテーマを選ぶ
- `記念日`: 約90日後の「受け直しの目安」を登録する
- 入口スキル(一般ツール集): 保存したタイプを、朝のまとめの「あなた」の部品に使う

## 安全性について(何をするか、全部書きます)

「安全です」と言い切るより、何をするかを並べます。気になる人はコードを読んでください(スクリプトは `scripts/typecheck.py` の1本、質問 `scripts/questions.json`、タイプの説明 `scripts/types.json`、ページのひな形 `scripts/page.html` です)。

**やること**
- 質問を出し、答えの点数を軸ごとに足して、タイプを決める
- 結果を `~/.claude/タイプ診断/results.json` に保存する(**日付・タイプ・軸の点数だけ**です。回答の中身や名前は保存しません)。保存先は環境変数 `TYPE_HOME` で変えられます

**やらないこと**
- **インターネットへの通信は、スクリプトからは一切しません。** 外へ送るための仕組み(urllib・requests・socket など)は使っていません
- ほかのスキルのファイルを、スクリプトから読み書きしません(連携は、AIが各スキルの指示に従って呼び出す形です)

**ひとつだけ注意**
- 「ページで出す」機能のひな形(`scripts/page.html`)は、見た目のために Google Fonts(フォント)を読み込みます。ページを開く時にだけ、フォントの取得で外部への通信が起きます
- 診断結果は個人的な内容です。結果のページや画面を他の人に見せる時は、自分で確認してからにしてください

**消す** → スキルのフォルダと、`~/.claude/タイプ診断/` フォルダを削除すれば、すべて消えます

## 入れ方

このフォルダの内容(`SKILL.md` と `scripts/`)を、お使いのAIツールのスキル置き場に `タイプ診断` という名前のフォルダで置きます。Claude Code なら `~/.claude/skills/タイプ診断/` です。

あとは「タイプ診断して」と話しかけます。

## 使い方

| やりたいこと | 話しかけ方 |
|---|---|
| 診断する | 「タイプ診断して」「性格を知りたい」 |
| 16タイプの説明を見る | 「16タイプを教えて」 |
| 前回と比べる | 「前回と比べて」 |

自己点検は `python scripts/typecheck.py check` で実行できます(質問の数、採点、タイプの説明がそろっているかを確かめます)。
